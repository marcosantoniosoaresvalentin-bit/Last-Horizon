# Fontes

- `caveat.fonte`: fonte **Caveat** (letra escrita à mão), de Impallari Type, do repositório
  github.com/google/fonts. Licença SIL Open Font License 1.1 (`caveat_OFL.txt`).
- `oswald.fonte`: fonte **Oswald** (letra condensada dos títulos e botões), de Vernon Adams,
  do repositório github.com/google/fonts. Licença SIL Open Font License 1.1 (`oswald_OFL.txt`).
- São os arquivos .ttf original com outra extensão, para a Godot não importar. O jogo carrega
  na hora (FontFile.data), por isso chega pela atualização automática.
